# Frontend Mentor - QR code component solution

This is a solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H). Frontend Mentor challenges help you improve your coding skills by building realistic projects. 

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox

### What I learned

This challenge gave me a better idea of how flexboxes work, the smantic html and hover options on the whatver you want to apply it on. After working on previous labs and projects this gave me a better grasp on flex boxes and how to manipulate the contents within it.
